# Smart Traffic Management System using AI and IoT

## Overview
An AI-powered adaptive traffic management system using YOLOv8 for real-time vehicle detection, tracking and density estimation. Designed by TY ECE students.

## Features
- Vehicle detection with YOLOv8
- Vehicle tracking and counting
- ROI optimization
- Density estimation
- Dynamic signal timing concept
- IoT-ready architecture
- Future emergency vehicle priority

## Folder Structure
- src/: Python source
- docs/: Presentation
- images/: Add screenshots
- demo/: Add demo video
- models/: YOLO model links

## Requirements
See requirements.txt

## Run
```bash
pip install -r requirements.txt
python src/traffic2.py
```
